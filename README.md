# BugWatch
Privacy-first community illness trends app for parents.

## Current build
- Expo + React Native foundation
- Community Pulse home screen
- South Africa selected as initial launch market
- No backend or personal/health data collection enabled yet

## Run locally
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npx expo start`.
